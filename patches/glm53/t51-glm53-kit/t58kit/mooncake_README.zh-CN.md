# Mooncake（T58）

这个补丁包里没有 Mooncake 的文件。T58 的 Mooncake 部分在单独的 Mooncake 增量包 v2 里：替换库 v2 由补丁 04b 编出，计时记录不再写进 vLLM 日志，改写进 `/data/pd-diag/logs/mooncake/` 下的文件（记录格式约定 1.5.0 第 8.4 节）。

- **粒度和开关：**
  - `PD_DIAG_LEVEL` 恰好是 `1` 或 `2` 时，替换库不写计时记录；不设、`3` 和其余值都按 3 级，照写；
  - `MC_PD_TIMING=0` 时也不写；
  - 两种情况都不退回标准错误。
- **检测脚本 glm53-8 认两版替换库：** v1（`3131784385846064…`，增量包 `6d70978c`）、v2，分别报 `mooncake=ok(v1)`、`mooncake=ok(v2)`；没换报 `mooncake=not_replaced`。
- **测试集群（现在是 v1）：** 换 v2 以前先备份现在的 v1，回滚用这份备份。
- **生产（原库）：** 直接换成 v2。换库前的核对和例外那一步照旧。
