# 文件地图：每个概念在哪个文件实现

路径相对于仓库根目录。`P1 = panel1/pack/vllm-pd-grafana-panel1`，`P2 = panel2/vllm-pd-grafana-panel2`。各文件的作用取自文件开头的说明。

## 两个面板共用

| 概念 | 文件 | 说明 |
|---|---|---|
| 集群的名字、端口、目录、注册表 `~/.vllm-pd-clusters.json` | `P1/scripts/names.py`、`P2/scripts/names.py` | 两份应保持相同（2026-11-19 核对：sha256 前 16 位均为 3162da0a005d7c9f）；面板二改了 `names.py` 时要复制到面板一并重新出包 |
| Grafana 两层文件夹（模型文件夹 / 集群文件夹） | `tools/arrange_boards.py`、`tools/boards_layout.txt` | 两个包都只认顶层文件夹 `MODEL_GROUP`；add / update / rollback 之后执行 `apply` |
| 单个集群的只读配置快照 | `tools/panels_snapshot.py` | 格式 2；只支持带面板一的集群 |
| 在用部署包的 sha256 | `releases/<tag>/SHA256SUMS` | 包本身在 GitHub Release |
| 现场值、已填路径版 | `local/`（不进 git） | 见 `docs/50-已知问题与待办.md` 附表 |
