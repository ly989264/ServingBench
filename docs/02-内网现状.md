# 02 内网现状

本文按集群列出内网监控机上部署了什么：名字、所属面板、用途、包版本、模式、端口、目录、节点数、集群之间的耦合、Grafana 文件夹树，以及监控机上的包和脚本。同样的内容以机器可读的形式放在 [`state/内网现状.yaml`](../state/内网现状.yaml)，两者应同时更新。组件和数据流的原理见 [01-全景](01-全景.md)。

## 0. 读法

**状态时点。** 2026-11-28。

- 面板一：线上 8 个集群（glm53-0、glm53-1、glm53-2、dsv41-flash-1 … 5）的 16 张看板升级到 v1.2。
- 面板二：线上 glm53-1 为 T53 完成的版本（v3.4-extra-t53，看板带整天快捷时间范围，与 pkg26 相同），接真实 vLLM；线下测试集群 test-glm53 换成 T62 采集进程方案（v4.0-extra），已部署、待验收（第 6 步核对有 1 项不符，原因在查）。

各升级的逐步带回输出没有全部见到，没有见到的按手册与包内容写，并在依据一列注明。还没有做完的变更写在第 11 节。

**依据一列的写法。**

| 写法 | 含义 |
|---|---|
| 内网带回 | 用户在内网执行后带回的输出（注明任务与日期） |
| 用户报告 | 用户报告做完（注明日期），逐步输出未见 |
| 手册 | 交付给内网、照其执行的手册（占位符版在 `manuals/`） |
| 按包推得 | 按交付的包内容推得，没有带回输出直接证明 |
| 说明书 | 《面板系统说明书》v3.1-extra（`docs/面板系统说明书.zh-CN.md`）第二部分；该部分记的是 2026-11-14 的状态，此后的变化另注 |
| 按手册与镜像推得，未经内网核对 | 由交付手册和实验室镜像（按交付给内网的同一批命令同步）推出，内网没有带回对应输出 |
| 未核实 | 没有可靠出处 |

**占位符。**

| 占位符 | 含义 | 现场值在哪里 |
|---|---|---|
| `<监控机>` | 监控机地址 | `local/site.env` |
| `<P节点1>`、`<D节点1>` 等 | 各集群的节点地址 | 各集群的 `inventory.json`；`local/` |
| `<proxy机器>` | 某集群 proxy 所在的机器 | 打补丁、升级时的现场值 |
| `<ROOT>` | 面板目录的上级目录（`VLLM_PD_ROOT`，手册中写作 `<总目录>`） | 包二 v3 已填路径更新脚本的 `ROOT` |
| `<用户目录>` | 监控机上放部署包和更新脚本的个人目录 | 同一脚本的 `USER_DIR` |
| `<SSH账号>` | 从监控机登录节点的账号（`deploy.env` 的 `SSH_USER`） | 各集群 `deploy.env` |
| `~` | 监控机上执行账号的家目录（装面板、执行更新脚本的账号） | — |
